# Requirements
- Ubuntu >20.04
- [Anaconda](https://www.anaconda.com/docs/getting-started/anaconda/install) 

1. Set up Conda environment
```
conda create -n tTLT python=3.8.18
conda activate tTLT
```

### [Inside conda environment]

2. Install dependencies
```
pip install -r requirements.txt
```


3. Install the `optimized_dp` repository
```
cd ~/PATH-TO/HJ-tTLT/optimized_dp
pip install -e .
```
